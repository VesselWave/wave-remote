Wave Remote 0.6.5 fits more phone sizes and larger text settings:

- Compact remote layouts keep controls visible without scrolling where they fit.
- Setup and menu actions stay reachable when the keyboard is open.
- Larger text remains readable in shortcuts, scrolling preferences, and touchpad instructions.
- A brief larger-arrow hint shows when more content is below; it disappears on scrolling or after a moment.

Installs over 0.6.4 and keeps your pairings and remote settings when signed with the same release key. To check the download: `sha256sum --check wave-remote-v0.6.5.apk.sha256`.

Layout verification covered nine Android emulator size/text configurations, plus a narrow cutout layout. Physical-device coverage remains limited; see the [QA report](https://github.com/VesselWave/wave-remote/blob/main/docs/qa/phone-layouts.md).

Setup and troubleshooting are in the [README](https://github.com/VesselWave/wave-remote#readme). Not affiliated with LG.

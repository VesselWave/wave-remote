Wave Remote 0.6.7 brings the VesselWave family look and connection fixes:

- Blue-black surfaces, electric blue controls, consistent corners, and a matching launcher icon shared with Wave VPN.
- Zero-padded TV IP addresses resolve to the same saved TV, keeping manual entry from creating duplicates.
- Oversized fragmented TV messages close the connection instead of buffering without a limit.

Installs over 0.6.6 and keeps your TV pairings and remote settings. Uses the same production signing key as the VesselWave F-Droid repository.

To check the download: `sha256sum --check wave-remote-v0.6.7.apk.sha256`.

Setup and troubleshooting are in the [README](https://github.com/VesselWave/wave-remote#readme). Not affiliated with LG.

Wave Remote 0.7.2

- Keeps the TV connection across app switches and checks it on return instead of disconnecting every time.
- Reconnects by checking the saved IP first when the TV has a known device identity; scans the network only if that check fails.

Installs over 0.7.1 and keeps TV pairings and settings. Uses the existing production signing key.

Check the download with `sha256sum --check wave-remote-v0.7.2.apk.sha256`. The release also includes OpenPGP-signed SHA256SUMS, source and provenance.

Setup: https://github.com/VesselWave/wave-remote#readme. Not affiliated with LG.
